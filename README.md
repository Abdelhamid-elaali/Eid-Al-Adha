# 🌙 Eid al-Adha Mubarak Landing Page

A premium, highly-polished, responsive landing page celebrating the spirit, meaning, and global traditions of **Eid al-Adha** (the Festival of Sacrifice). 

Designed with rich aesthetics, smooth animations, and cultural motifs, this website acts as a beautiful digital greeting and educational resource for the blessed days of sacrifice and gratitude.

---

## ✨ Features

*   **Premium Visual Design:** Curated color palette featuring deep green, gold accents, and a warm cream background.
*   **Geometric Islamic Pattern:** A clean, subtle, and responsive SVG geometric background.
*   **Smooth Scroll Animations:** Scroll-triggered reveal animations for sections to create a premium, interactive user experience.
*   **The Four Pillars:** Interactive Cards highlighting the core aspects of Eid: *Prayer, Sacrifice, Giving,* and *Togetherness*.
*   **Global Traditions:** A dedicated showcase of how Eid al-Adha is celebrated worldwide (new clothes, feasts, visits, and charity).
*   **SEO Optimized:** Ready-to-deploy metadata, Open Graph (OG) tags, and Twitter Cards for social sharing.
*   **Fully Responsive:** Looks stunning on all devices from small smartphones to large desktop screens.

---

## 🛠️ Built With

*   **HTML5** - Structured semantically for optimal accessibility and search visibility.
*   **Vanilla CSS3** - Custom styling, CSS custom properties, and CSS keyframe animations for high performance.
*   **JavaScript** - Lightweight interaction using the modern `IntersectionObserver` API for smooth scroll reveals.

## 🚀 Getting Started

### Local Preview
To preview this landing page on your local machine:
1. Clone or download this repository.
2. Open [eid_al_adha_landing_page.html](eid_al_adha_landing_page.html) directly in any web browser.

### Deployment on GitHub Pages
This project is pre-configured and ready to be hosted on **GitHub Pages**:
1. Push this project to a public repository on GitHub.
2. Rename `eid_al_adha_landing_page.html` to `index.html` (recommended for root routing).
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Select the branch (e.g., `main` or `master`) and folder (e.g., `/root`) and click **Save**.
5. Your website will be live in a few minutes!
